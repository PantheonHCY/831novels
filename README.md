# 上善若🌿选集

收录百度贴吧「生个女孩吧」上善若🌿老师作品的个人文库，纯静态站点，部署于Github Pages

## 主要功能

- **筛选**：按年份 / 月份 / 常见成员筛选；多标签 AND 筛选（如同时含「刘增艳」与「袁雨桢」）；标题关键字筛选（如「相声」）
- **浏览**：列表分页、正文前 5 行预览、按日期倒序
- **随机跳转**：🎲 随便看看（首页随机开一篇）/ 🎲再看一篇（文章页随机切一篇）

## 标签规则

按成员在正文中的出现次数降序生成标签；出现次数相同时，按姓名逐字笔画排序（笔画数升序，同笔画数按起笔笔形「横竖撇点折」）。
